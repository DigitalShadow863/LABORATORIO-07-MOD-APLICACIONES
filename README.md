# Tema 7: Gestión del Cambio y Trazabilidad Integral

Repositorio del laboratorio de **Modelado y Desarrollo de Aplicaciones (CIIN1322P)** sobre control de cambios, versionamiento y trazabilidad (`Req-CU-Clase-Prueba`) aplicado a un módulo de reservas y check-in.

## Convención de IDs
* `RF-XXX`: Requisitos Funcionales
* `CU-XXX`: Casos de Uso
* `CL-XXX`: Clases UML
* `CP-XXX`: Casos de Prueba
* `CR-XXX`: Solicitudes de Cambio (*Change Requests*)

## Versiones y Trazabilidad
* **`v1.0` (Baseline):** Alcance inicial (`RF-001` a `RF-003`), modelo UML base y matriz de trazabilidad inicial.
* **`v1.1` (Actual):** Integra `CR-001` (penalidad del 20% por cancelación con menos de 24 h de anticipación), incorporando `RF-004`, `CU-004`, actualizaciones en `CL-001 (Reserva)`, `CP-004` y correcciones de revisión por pares.
